CONNECTION MANAGER

Set API

API key được mã hóa ở backend. Trình duyệt chỉ nhận trạng thái kết nối, không nhận secret đã lưu.

Thiết lập AI API nâng cao

Dùng cho Custom AI REST hoặc server AI có API riêng. Local AI/OpenAI-compatible không cần cấu hình phần này nếu dùng chuẩn /models và /chat/completions.

Thiết lập Voice API nâng cao

Dùng cho OpenAI-compatible TTS, OmniVoice hoặc Voice server REST khác. Nếu server có API riêng, khai báo endpoint và mapping tại đây.
